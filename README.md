# Open Fiber — Demo Control Room

Due demo HTML statiche pubblicate tramite GitHub Pages.

- [Pagina iniziale](https://servizicreativedst.github.io/OF-demo/)
- [Digital Control Room (3.7 / 5.1)](https://servizicreativedst.github.io/OF-demo/digital-control-room.html)
- [Advanced Digital Control Room (5.2)](https://servizicreativedst.github.io/OF-demo/advanced-digital-control-room.html)

Gli HTML delle due demo mantengono contenuti e funzionalità dei file originali, con nomi semplificati per gli URL. Immagini, font e librerie sono incorporati.

Le tre pagine HTML includono la direttiva `noindex, nofollow, nosnippet, noimageindex`. Nelle demo, la direttiva è presente sia nell'HTML iniziale sia nel template che sostituisce il documento dopo l'avvio.

Le pagine si aprono senza password. Queste direttive sono richieste ai motori che le rispettano, non un controllo degli accessi: non impediscono lo scaricamento o il crawling da parte di altri bot. Anche questa repository rimane pubblica.

Non viene aggiunto un blocco `robots.txt`, perché impedire la scansione impedirebbe ai motori di leggere `noindex`. Su questo sito di progetto un `robots.txt` in `/OF-demo/` non avrebbe comunque effetto: il file dovrebbe essere alla radice del dominio.

GitHub Pages: pubblicazione dalla radice (`/`) del branch `main`.
